# Illust Bloom 🌱

**毎日3分、小さな練習から大きな開花へ。**

Illust Bloom は、イラスト初心者のための練習サポートアプリです。

短時間の練習やお題への挑戦、日々の記録を通じて、無理なく楽しく描き続けることを目指しています。

## ✨ 主な機能

### 1. X秒ドローイング
表示されたポーズや顔、手などのお手本を見ながら、制限時間内に描く練習機能です。

短い時間で集中して描くことで、描く習慣づくりをサポートします。

### 2. お題ジェネレーター
描くテーマに迷ったときに、ランダムなお題を生成できます。

何を描こうか悩む時間を減らし、気軽に描き始められます。

### 3. 成長記録
描いたイラストを日付とともに記録できます。

過去の作品を振り返り、自分の成長を確認できます。

### 4. メリハリタイマー
練習時間と休憩時間にメリハリをつけるためのタイマー機能です。

集中しすぎず、自分のペースで練習を続けることをサポートします。

### 5. 習慣化サポート
日々の練習を継続するためのサポート機能です。

通知などを活用し、練習を習慣にするきっかけを作ります。

### 今後の実装予定：プロ絵師解説
プロのイラストレーターによる解説コンテンツを、正式版で実装予定です。

## 📱 インストール方法

1. 上記のリリースページをAndroid端末で開きます。
2. 最新版のAPKファイルをダウンロードします。
3. ダウンロードしたAPKファイルを開きます。
4. 「不明なアプリのインストール」などの許可を求められた場合は、画面の案内に従って許可してください。
5. 「この提供元のアプリはインストールできません」と表示された場合は「設定」を開き、ブラウザに対して「この提供元のアプリを許可」をオンにしてください。
6. Play プロテクトの警告が出る場合は、「詳細」から「インストールする」を選んでください。
7. インストール完了後、Illust Bloomを起動してください。

※ Google Playを経由しないAPK形式での配布です。インストール時に警告が表示される場合があります。

## 🔒 広告・通知・画像データについて

### 広告について
現在のβ版では、習慣化サポートおよびメリハリタイマーにテスト広告を表示しています。

正式版での広告の取り扱いについては、今後変更となる場合があります。

### 通知について
習慣化サポート機能では、練習の継続をサポートするために通知を利用します。

アプリを閉じている状態でも通知を受け取ることができます。

通知を受け取るには、端末側で通知を許可する必要があります。

### 画像データについて
成長記録に登録した画像は、現在のAndroid版では端末内に保存されます。

そのため、アプリのアンインストールや端末の故障・機種変更などによって、画像データが失われる可能性があります。

大切な作品は、必要に応じて端末外にもバックアップを取っておくことをおすすめします。
